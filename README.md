# 🎓 AI-Based Student Performance Prediction System

## 📌 Project Overview
This project uses Machine Learning to predict student performance based on various factors such as study hours, attendance, past exam scores, and other attributes. The goal is to analyze student data and provide insights to improve academic outcomes.

## 🚀 Features
- Data preprocessing and cleaning
- Handling categorical data using encoding
- Exploratory Data Analysis (EDA)
- Model building using Linear Regression
- Performance evaluation using R² Score
- Visualization of Actual vs Predicted results

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Dataset Features
- Study Hours per Week
- Attendance Rate
- Past Exam Scores
- Parental Education Level
- Internet Access
- Extracurricular Activities
- Final Exam Score (Target Variable)

## 🤖 Machine Learning Model
- Linear Regression

## 📈 Results
- Achieved an R² Score of approximately 0.78
- Model shows good prediction performance

## 🎯 Use Case
- Identify weak students early
- Help teachers improve student outcomes
- Support data-driven decision making in education

## 📌 Conclusion
The model successfully predicts student performance with good accuracy and can be further improved using advanced algorithms.
